# Ansim Car · 安心车险

한국 거주 중국인을 위한 중국어 자동차보험 상담 사이트. 정적 HTML/CSS/JavaScript로 동작합니다.

## 모바일 UI 및 상담 채널

딥블루 `#1E3A8A`와 오렌지 `#F97316`, 제주 10년 경력 전문가 배지, 제주 안내 카드, 아이콘 입력창, 하단 고정 상담 바를 사용합니다. 3분은 자료 입력 목표이며 즉시 확정 견적을 약속하지 않습니다.

WeChat 상담 ID는 운영자가 제공한 `minseo627`입니다. 상담 버튼을 누르면 ID 복사와 위챗 검색 추가 안내가 표시됩니다. 자동 메시지 전송, 가짜 QR 코드, 미지원 친구 추가 링크를 사용하지 않습니다. 클립보드 권한이 없으면 길게 눌러 수동 복사할 수 있습니다.

## 실행

별도 설치나 빌드 없이 `index.html`을 열거나 저장소 루트를 정적 웹 서버로 제공하세요.

## 2단계 신청 흐름

1. 이름, 한국 연락처, 차량번호, 차량등록증 사진, 필수 개인정보 안내 동의만 확인합니다. 선택 동의 없이도 진행할 수 있습니다.
2. 선택 정보: 운전자 범위, 만기일, 3가지 보장 선호, 운전면허 사진, 사고 이력, 할인할증 등급, 해외 보험 경력과 증명 사진. 상단과 하단에서 모두 건너뛸 수 있습니다.

전체 동의는 기본 미선택이며, 펼치면 필수/선택을 개별 변경할 수 있습니다. 선택 항목에는 미입력/모름 경로가 있으며 전문가 확인을 전제로 합니다. 보장 3종은 상담 선호이며 실제 보험 상품이나 확정 견적이 아닙니다.

## 현재 구현 범위

- 신청 동선과 항목별 오류 표시, 터치 선택, 사진 촬영/앨범 선택, 본페이지 미리보기/삭제
- JPG/PNG/WebP 10 MB 제한 및 이미지 디코딩 확인
- 선택 단계 건너뛰기, 같은 페이지에서 이어서 작성, 기초 정보 수정
- 텍스트 요약 다운로드(사진 제외), 자료 초기화
- 내용은 페이지 메모리에만 존재하며 서버 전송, 브라우저 영구 저장, URL 내 개인정보 전달 없음
- 페이지 새로고침/종료/이탈 또는 초기화 시 사진 객체 URL과 입력을 해제

사진은 테스트 이미지로 검증하세요. 실제 민감한 증빙 자료는 입력하지 마세요. 사용자가 다운로드한 요약 파일은 사용자 기기에 남습니다. Google Fonts 외 앱 데이터 전송 기능은 없습니다.

## 실제 운영에 필요한 연결

현재 **실제 리드 접수, 사진 업로드 서버, OCR, 보험사 견적, 문자/위챗 발송, 외부 기기에서 이어쓰기, 채팅 상담은 구현되지 않았습니다.** 화면은 일관되게 전송되지 않은 미리보기로 표시합니다.

실제 서버 연결 시에는 1단계 리드를 독립 저장한 후 접수 성공 응답을 받은 경우에만 신청 성공을 표시해야 합니다. 2단계는 별도 선택 업데이트로 처리하고, 건너뛰어도 1단계 리드가 유지되어야 합니다. 업로드와 리드 저장 실패에는 재시도 경로를 제공하고 중복 접수를 방지해야 합니다.

운영 주체, 연락처, 개인정보 처리 수탁/제공 범위, 실제 보관 기간과 삭제/철회 절차는 운영자가 확정해야 합니다. 본 미리보기의 '현재 페이지 동안 임시 보관'은 서버 보관 정책을 대신하지 않습니다. 확정되지 않은 서버 보관 기한이나 자동 삭제를 약속하지 않습니다.

OCR은 차량등록증/면허/해외보험 증명별 허용 필드만 추출하고 결과를 이용자가 확인하도록 연결하세요. 원본 보관 여부, 접근 권한, 암호화 및 삭제 정책을 먼저 확정해야 합니다.

문자/위챗 이어쓰기에는 동의된 수신 채널과 인증된 발송 계정이 필요합니다. 단기 만료 일회성 링크를 사용하고, URL에 이름·전화번호·증빙 자료를 넣지 마세요. 외부 채널로는 이 구현에서 아무 메시지도 전송하지 않습니다.
