# Ansim Car · 安心车险

한국 거주 중국인을 위한 중국어 자동차보험 비교 상담 사이트입니다.

## 실행

별도 설치나 빌드 없이 `index.html`을 브라우저에서 열거나, 저장소 루트를 정적 웹 서버로 제공하면 됩니다.

## 파일

- `index.html`: 중국어 홈페이지 및 2단계 상담 양식
- `style.css`: PC·모바일 반응형 스타일
- `app.js`: 입력 검증, 상담 요약 생성 및 텍스트 다운로드

## 현재 상태

서비스 미리보기 버전입니다. 입력 내용은 현재 브라우저에서만 처리되며 서버로 전송하거나 영구 저장하지 않습니다. 실제 보험료 조회, 상담 접수, 보험 가입 및 결제는 연결되지 않았습니다.

실제 운영 전 운영 주체, 보험 업무 자격, 상담 연락처, 개인정보 처리방침 및 접수·보험사 연동을 준비해야 합니다.

중국어 글꼴은 Google Fonts를 사용하며, 연결되지 않으면 시스템 글꼴로 표시됩니다.
